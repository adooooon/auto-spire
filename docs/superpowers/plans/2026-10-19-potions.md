# Potions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 12 direct-effect potions in the sim (slots, fight drops, shop stock, combat use, and Blood Potion between fights), with the combat and run policies grown to see and use them, then retrained.

**Architecture:**
- **`sim/potions.py`** lists the potions.
- **`SimCombat`** holds 3 potion slots and applies the potions' effects, and gains Dexterity.
- **`env.py`** appends potion observations and "use potion" actions after the existing ones. The sim reports slots under a sim-only `potionSlots` key, so live play never sees a potion.
- **`sim/act.py`** adds potion drops, shop potions and Blood Potion drinking to `Run`.
- **`run_env.py`** appends a potion decision, shop potion buys and drinking.
- **`grow.py`** copies v10 and run policy v2 into the larger spaces, with zero weights for everything new, so both start out playing exactly like their parents.

**Tech Stack:** Python 3.13 (`.venv`), gymnasium, stable-baselines3 2.9 + sb3-contrib 2.9 MaskablePPO, torch (CPU), numpy.

**Spec:** `docs/superpowers/specs/2026-10-19-potions-design.md`

```python
    def use_potion(self, slot: int, target_id: int | None = None) -> dict:
        """PotionModel.OnUse for the modeled potions; target_id is an enemy combatId (enemy potions only).
        Potion damage and Block Potion's block are Unpowered: block absorbs the damage, but Strength,
        Vulnerable, Weak, Shrink, Dexterity and Frail don't apply (ValuePropExtensions.IsPoweredAttack)."""
        if not self.in_combat or not self.is_play_phase:
            return {"error": "not_play_phase"}
        if not 0 <= slot < len(self.potions) or self.potions[slot] not in POTIONS:
            return {"error": "invalid_potion", "slot": slot}
        pid, target = self.potions[slot], None
        if POTIONS[pid] == "enemy":
            target = self.enemies[target_id - 1] if target_id and 0 < target_id <= len(self.enemies) else None
            if target is None or not target.is_alive:
                return {"error": "invalid_target", "targetId": target_id}
        self.potions[slot] = None
        if pid == "BLOCK_POTION":
            self._gain_block(12)
        elif pid == "DEXTERITY_POTION":
            self.dexterity += 2
        elif pid == "SPEED_POTION":
            self.dexterity += 5
            self.temp_dexterity += 5
        elif pid == "ENERGY_POTION":
            self._gain_energy(2)
        elif pid == "STRENGTH_POTION":
            self.strength += 2
        elif pid == "FLEX_POTION":
            self.strength += 5
            self.temp_strength += 5
        elif pid == "SWIFT_POTION":
            self._draw(3)
        elif pid == "FIRE_POTION":
            self._damage_enemy(target, 20)
        elif pid == "EXPLOSIVE_AMPOULE":
            for e in self._hittable():  # HittableEnemies, read once before the hits
                self._damage_enemy(e, 10)
        elif pid == "VULNERABLE_POTION":
            self._debuff(target, "vulnerable", 3)
        elif pid == "WEAK_POTION":
            self._debuff(target, "weak", 3)
        elif pid == "BLOOD_POTION":
            self.heal(self.player_max_hp * 20 // 100)  # 20% of max HP, truncated
        self._check_win()
        return {"ok": True, "used": pid, "slot": slot}
```

```markdown
## Potions

Ported to the sim in `agent/sim/potions.py` and `SimCombat.use_potion`; drops and shops in `agent/sim/act.py`.

- **Slots:** 3 (`Player.initialMaxPotionSlotCount`).
- **Pools:** `SharedPotionPool` plus the character's pool. Ironclad's is `Ironclad4Epoch.Potions` (Blood Potion, Ashwater, Soldier's Stew) once that epoch is revealed. Each rarity has 16 potions across the two pools.
- **Damage and block types:** potion damage and Block Potion's block are `ValueProp.Unpowered` ("damage from relics, potions, and powers").
  - Strength, Vulnerable, Weak, Shrink and Slow only modify `IsPoweredAttack` damage (Move and not Unpowered).
  - Dexterity and Frail only modify `IsPoweredCardOrMonsterMoveBlock` block.
  - So potion damage is flat, block still absorbs it, and Block Potion gives exactly 12.
- **Direct-effect Commons:**
  - Block 12
  - Dexterity +2
  - Speed +5 Dexterity this turn (`SpeedPotionPower`)
  - Energy +2
  - Strength +2
  - Flex +5 Strength this turn (`FlexPotionPower`)
  - Swift: draw 3
  - Fire: 20 damage
  - Explosive Ampoule: 10 to each `HittableEnemies`
  - Vulnerable 3
  - Weak 3
  - Blood (Ironclad): heal 20% of max HP, `PotionUsage.AnyTime`, so it also works between fights. The rest are `CombatOnly`.
- **Card-choice Commons:** Attack, Skill, Power and Colorless Potion pick 1 of 3 generated cards.
- **Healing truncates:** `Creature.SetCurrentHpInternal` casts to int, so 20% of 83 heals 16.
- **Dexterity** (`DexterityPower.ModifyBlockAdditive`) adds before Frail's ×0.75 (`ModifyBlockMultiplicative`).
- **Drops** (`PotionRewardOdds`):
  - The chance starts at 0.4. A roll succeeds when a random number is below the chance (plus 0.25 × 0.5 in elite rooms).
  - Success lowers the chance by 0.1; failure raises it by 0.1.
  - Monster, Elite and Boss rewards each roll (`RewardsSet.RollForPotionAndAddTo`).
- **Rarity** (`PotionFactory.CreateRandomPotion`): a random float ≤ 0.10 is Rare, ≤ 0.35 Uncommon, otherwise Common. The potion is then uniform within that rarity, and multi-potion rolls don't repeat.
- **Shop** (`MerchantInventory.PopulatePotionEntries`):
  - 3 random potions, priced 50 / 75 / 100 by rarity × U(0.95, 1.05), rounded (`MerchantPotionEntry.GetCost`).
  - A potion can only be bought into a free slot.
```

```python
"""Grow a trained MaskablePPO into a bigger observation/action space (sub-project 2: potions).

Every old weight is copied; weights from new inputs and to new actions start at zero, so the grown
model acts exactly like the old one until training moves them. New inputs and actions must be
appended (old indices unchanged), as env.py and run_env.py do. From agent/:
    python grow.py models/ppo_sts2_sim_act1_map_v10_final.zip models/ppo_sts2_sim_act1_map_v10p.zip --env combat
    python grow.py models/ppo_sts2_sim_run_policy_v2_final.zip models/ppo_sts2_sim_run_policy_v2p.zip --env run
"""
from __future__ import annotations

import argparse

import torch
from sb3_contrib import MaskablePPO


def grow(old: MaskablePPO, env) -> MaskablePPO:
    new = MaskablePPO("MlpPolicy", env, n_steps=old.n_steps, batch_size=old.batch_size, n_epochs=old.n_epochs,
                      learning_rate=old.learning_rate, gamma=old.gamma, policy_kwargs=old.policy_kwargs,
                      device="cpu", verbose=1)
    state = new.policy.state_dict()
    for key, w in old.policy.state_dict().items():
        assert all(o <= n for o, n in zip(w.shape, state[key].shape)), (key, w.shape, state[key].shape)
        grown = torch.zeros_like(state[key])
        grown[tuple(slice(0, s) for s in w.shape)] = w
        state[key] = grown
    new.policy.load_state_dict(state)
    new.num_timesteps = old.num_timesteps
    return new


def _heads(model: MaskablePPO, obs: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
    with torch.no_grad():
        pi, vf = model.policy.mlp_extractor(model.policy.extract_features(obs))
        return model.policy.action_net(pi), model.policy.value_net(vf)


def check(old: MaskablePPO, new: MaskablePPO, n: int = 256) -> bool:
    """Same logits on the old actions and same value, whatever the new inputs hold; new actions at 0."""
    obs = torch.randn(n, old.observation_space.shape[0])
    extra = torch.randn(n, new.observation_space.shape[0] - obs.shape[1])
    lo, vo = _heads(old, obs)
    ln, vn = _heads(new, torch.cat([obs, extra], 1))
    k = old.action_space.n
    return bool(torch.allclose(lo, ln[:, :k], atol=1e-5) and torch.allclose(vo, vn, atol=1e-5)
                and (ln[:, k:] == 0).all())


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("old")
    ap.add_argument("new")
    ap.add_argument("--env", choices=["combat", "run"], required=True)
    args = ap.parse_args()
    if args.env == "combat":
        from env import STS2CombatEnv
        from sim.engine import SimClient
        env = STS2CombatEnv(client=SimClient())
    else:
        from run_env import RunPolicyEnv
        env = RunPolicyEnv()
    old = MaskablePPO.load(args.old, device="cpu")
    new = grow(old, env)
    if not check(old, new):
        raise SystemExit("grow self-check failed; not saved")
    new.save(args.new)
    print(f"grow self-check ok: {old.observation_space.shape[0]}->{new.observation_space.shape[0]} inputs, "
          f"{old.action_space.n}->{new.action_space.n} actions, saved {args.new}")


if __name__ == "__main__":
    main()
```
