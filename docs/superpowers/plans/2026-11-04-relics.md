# Relics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 97 relics with real effects in the sim, plus honest drops (elites, treasure, shops) from the full 122-relic pool, with the combat and run policies grown to see and use them, then retrained.

**Architecture:**
- **`sim/relics.py`** lists the pool and which relics are modeled.
- **`SimCombat`** holds a set of relics, a carried counter dict shared with `Run`, and per-fight state, and calls relic rules at the game's hook points.
- **`Run`** owns the grab bags, treasure and shop relics, run-level effects (gold, max HP, rest, prices) and a queue of extra rewards.
- **`env.py` and `run_env.py`** append observations and actions, so `grow.py` keeps working. The sim reports relics under sim-only keys, so live play never sees them.

**Tech Stack:** Python 3.13 (`.venv`), gymnasium, stable-baselines3 2.9 + sb3-contrib 2.9 MaskablePPO, torch (CPU), numpy.

**Spec:** `docs/superpowers/specs/2026-11-04-relics-design.md`

def _no_relic_trace() -> str:
    """Every fight state on seeded random play. Any change here means relic code leaked into relic-less fights."""
    h = hashlib.sha256()
    for seed in range(66):
        rng = random.Random(seed)
        c = SimCombat(rng=random.Random(seed))
        c.potions = [rng.choice(POTION_IDS), None, rng.choice(POTION_IDS)]
        c.fight(ENCOUNTERS[seed % len(ENCOUNTERS)], starter_deck() + rng.choices(COMMONS + UNCOMMONS + RARES, k=6))
        for _ in range(300):
            if not c.in_combat:
                break
            playable = [i for i, x in enumerate(c.hand) if c.can_play(x)]
            try:
                if rng.random() < 0.05:
                    c.use_potion(rng.randrange(3), 1)  # an empty slot or dead target just returns an error
                c.play_card(rng.choice(playable)) if playable and rng.random() < 0.8 else c.end_turn()
            except SimLoopError:
                break
            h.update(repr((c.player_hp, c.player_block, c.energy, c.hand, c.round, [e.hp for e in c.enemies])).encode())
    return h.hexdigest()

assert _no_relic_trace() == "GOLDEN"
